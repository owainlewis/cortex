# Cortex v0.2.0

Cortex v0.2.0 makes the macOS terminal editor safer, faster, and more useful for everyday work.

## Highlights

- Opens files and directories through a nested picker, including symlinks to regular files.
- Keeps multiple file buffers open and supports find-file and switch-buffer workflows.
- Reloads agent-modified files safely, with dirty-buffer protection and a visible disk-change warning.
- Edits complete Unicode grapheme clusters and keeps the point visible on long lines.
- Renders only changed terminal cells and bounds work for long files, long lines, syntax highlighting, and gutter markers.
- Preserves Rust and Markdown syntax context across deep viewports, fenced blocks, block quotes, and oversized lines.
- Hardens atomic saves against symlink races, metadata loss, inherited ACLs, and filesystem name limits.
- Restores terminal modes, the cursor, and the alternate screen after normal exits and catchable termination signals.
- Adds performance guardrails for editing, rendering, search, and deep syntax highlighting.
- Ships deterministic macOS arm64 archives with checksums and signed GitHub build provenance.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/owainlewis/cortex/main/install.sh | bash
```

The installer downloads the latest macOS arm64 release, verifies its checksum, and installs `cortex` to `~/.local/bin` by default.

## Upgrade

Run the installer again:

```sh
curl -fsSL https://raw.githubusercontent.com/owainlewis/cortex/main/install.sh | bash
```

Confirm the installed version:

```sh
cortex --version
```

## Notes

- Cortex binary releases require Apple silicon (arm64).
- Search is forward-only and not yet incremental.
- One buffer is visible at a time.
- There are no splits, tabs, config, plugins, LSP, AI integration, or embedded terminal pane yet.
- Long lines are clipped rather than wrapped.
- External file changes are detected when Cortex checks the file; they are not watched continuously.
